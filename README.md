# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/PRADEEVERMA/NexaChat.git
```

---

## Backend

```bash
cd backend
npm install
```

Create `.env`

```env
PORT=5000

MONGODB_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET

CLIENT_URL=http://localhost:5173

COOKIE_DOMAIN=


```

Run Backend

```bash
npm run dev
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
